# PhotoShoot

This monitors a folder for new pictures.
My camera will automatically upload new pictures to this folder via FTP, and this program will detect them and process them accordingly.
Clients will be able to view the pictures in a web interface, and the program will also generate thumbnails for quick viewing.
As new images are added, the program will automatically update the web interface to display them.

## Summary

Outlined the exact Blazor Server implementation for FTP ingestion, local folder monitoring, SignalR notifications, image routing, and supporting tests for this workspace.
